① 多任务管理
自研并日频在用 Session 看板 + Chrome 插件做日常任务并发执行，下一步探索与其他 builder 联机 fork
② 性能评测 + HUD
正在探索 ClawRank 跑分——量化不同用户个性化 Harness 产出效率的关键一步，业界还停留在 HUD，基于跑分的 ranking 更本质
Context 持续性 > Context 长度
"会话卡住了，继承它"出现 4 次以上。痛点是断点恢复，不是更大窗口。
Skill 发现机制 > Skill 能力本身
114 个 skill 高频集中前 20%——80% 没被推荐触发。distribution 问题，capability 没问题。
输入质量管理 > 模型能力提升
prompt-forge 用 10+ 次后确认：任务描述质量 ≈ Agent 成功率。Harness 该做输入引导。
展开另外 4 条判断
多 Agent 通信协议 > 单 Agent 功能增强
地推宝联调踩到：前后端 Agent 没有通信规范，任务中间断掉。
授权粒度 > 功能丰富度
"Agent 拿到 Key 怎么办"反复出现。精细授权是放心用的前提。
企业场景 = 数据处理，不是对话
物美 68 条 session 全是 xlsx · 飞书 · SQL · 合同审核。工具集权重该调。
Session 管理 > 功能迭代
使用量增加后检索急剧变慢。语义检索 + 摘要索引是留住重度用户的关键。
